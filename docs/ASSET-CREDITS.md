# Asset provenance

SAVE SLOT is an independent portfolio concept built with AI assistance. This page describes the materials used in the published experience; it does not grant a new project-wide licence.

## Console

The console source was created with one Meshy 7 Ultra generation through Higgsfield. Blender cleanup corrected the cartridge aperture and body proportions, separated the control, cleaned materials and reduced the mesh for browser use. The screen and indicator are independent runtime elements.

- [Published browser model](../public/media/console.glb)
- [Model inspection](../art/source/console-report.json)

## Procedural scene and games

The shelf, box panels, hinged flaps and cartridge parts are assembled from Three.js geometry. Shared geometry is combined with the six sets of supplied artwork. Scene assembly and transitions are implemented for the browser, with GSAP coordinating the physical sequence. Six Canvas2D mini-games provide the live console-screen texture.

The project combines a generated-and-cleaned console model with procedural 3D and browser game logic. It is not represented as entirely hand-modelled work.
